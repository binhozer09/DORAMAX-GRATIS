DORAMAX-GRATIS - projeto Android (Kotlin)

ARQUITETURA DO APLICATIVO
- Supabase e a fonte central dos dados e configuracoes remotas.
- O catalogo oficial fica em public.videos; o app consulta somente is_active = true.
- Configuracoes remotas ficam em public.app_settings.
- Login, perfis, permissoes e notificacoes administrativas usam Supabase Auth e Postgres.
- O painel ADM permite sincronizar os videos recentes diretamente do feed RSS do canal do YouTube para o Supabase pela Edge Function sync-videos. O codigo da funcao fica versionado em supabase/functions/sync-videos/.
- O Supabase tambem executa uma sincronizacao automatica a cada 30 minutos usando pg_cron + pg_net, sem depender do GitHub em tempo de execucao.
- A sincronizacao automatica usa o ID imutavel verificado do canal Lucas (UCmbVDAVpU2jKOQ_HTLtvxwA) e valida o nome do feed antes de gravar, evitando importar videos de outro canal se o @ mudar de destino.
- O catalogo ativo conferido nesta revisao contem 542 videos do canal Lucas e nenhum video ativo de outra origem.
- A sincronizacao e restrita a administradores autenticados e preserva videos marcados como manual_override.
- O catalogo e aplicado primeiro a partir do cache local e atualizado em segundo plano.
- Configuracoes remotas tambem sao armazenadas localmente para manter tema e avisos disponiveis sem rede.
- O Android WebView usa cache HTTP em disco para reutilizar recursos ja carregados, incluindo miniaturas do YouTube.
- O app solicita armazenamento persistente quando o WebView oferece suporte; o sistema ainda pode limpar dados se o usuario apagar os dados do app.
- O catalogo e as configuracoes em cache ficam disponiveis offline; a reproducao dos videos continua dependendo da internet e do YouTube.
- O YouTube continua hospedando e transmitindo os videos.
- Nao ha imagens estaticas externas do projeto para armazenar no Supabase Storage neste momento; as miniaturas sao servidas pelo YouTube.
- GitHub guarda somente o codigo-fonte, as migrations SQL, o codigo das Edge Functions e a configuracao do build. O app nao baixa catalogo, configuracoes ou scripts do GitHub em tempo de execucao.
- Os catalogos JSON antigos foram removidos do repositorio; public.videos e a fonte oficial.
- As alteracoes de schema e RLS estao versionadas em supabase/migrations/.

COMO GERAR O APK
Opcao 1 - Codemagic
1. Conecte o repositorio binhozer09/DORAMAX-GRATIS ao Codemagic.
2. Execute o workflow android-debug definido em codemagic.yaml.
3. Baixe o APK nos artefatos do build.

Opcao 2 - Android Studio
Abra a pasta no Android Studio, aguarde o sync e use Build > Build APK(s).

CATALOGO DE VIDEOS
Gerencie os registros e o campo is_active em public.videos no Supabase.
Para buscar os videos mais recentes do canal, entre no painel DORAMAX ADM e use SINCRONIZAR CANAL DO YOUTUBE.
O aplicativo guarda uma copia local do catalogo para abertura rapida e consulta offline.

VERSOES: Gradle 8.7, Android Gradle Plugin 8.5.2, Kotlin 1.9.24, JDK 17, minSdk 26 (Android 8+).
